# 🏦 Banking Management System

A simple command-line based Banking Management System written in Python. It allows users to create bank accounts, deposit and withdraw funds, and check account balances.

## 🚀 Features

- Create new bank accounts
- Deposit money
- Withdraw money
- Check balance
- View account information
- Menu-driven interface

## 🛠️ Technologies Used

- Python 3
